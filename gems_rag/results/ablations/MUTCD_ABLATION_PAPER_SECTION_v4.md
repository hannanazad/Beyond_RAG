## Ablation Study

We used the original Claude Fable 5 RAG run as the baseline and held the model, few-shot prompt, 150-question MUTCD benchmark, and scoring rubric fixed across six ablations. Each run removed one component: the question router, VLM figure filter, graph-proximity term, rule-type term, hierarchy prior, or reranker. The updated archives contain 900 valid responses, six ranked text chunks, and four page candidates per question. All provider calls ended normally. The no-router run also repaired the 18 records that had failed in the earlier submission.

The baseline achieved **88.08/100** on the 97 measurable points. Removing the VLM figure filter, graph term, or rule-type term produced full scores of **88.06**, **88.13**, and **88.24**, respectively. Removing the hierarchy prior reduced the score to **87.86**. The paired question bootstrap placed each of these changes within an interval containing zero. These single-run differences do not show that any of the four components lacks value, and they do not support removing a component that produced a small positive point estimate.

The reranker produced the clearest contribution. The no-reranker configuration scored **83.43/100**, a reduction of **4.65 points** from the baseline. Recall@5 fell from **86.7%** to **76.0%**, and the retrieval component fell from **19.35** to **17.78/25**. Correctness declined by **5.9 percentage points**, completeness by **5.6 points**, citation localization by **6.1 points**, and strict full credit by **11.3 points**. Its paired bootstrap interval for the full-score change was **[-6.91, -2.60]**, which remained below zero under question-level resampling.

The VLM figure filter controlled visual noise. Removing it increased exact required-visual recovery from **76.5%** to **85.9%**, but visual precision fell from **72.5%** to **23.5%**. The no-filter run supplied an average of **3.55** figure or table entities per visual question. The full system supplied **1.35**. The aggregate end-to-end score changed little because visual precision remains a diagnostic metric rather than a weighted term in the 25-point retrieval score.

Disabling the router reduced routing accuracy from **78.0%** to **56.7%**. The run sent visual evidence for all questions, including the 65 questions without a locked table or figure requirement. Router confidence does not exist in this condition, so we did not calculate Brier score, ECE, the 12-point reliability component, or the 97-point full score. On the common 91-point basis that excludes calibration and repeatability, the no-router run scored **88.34/100**, compared with **88.27** for the baseline. Its paired interval contained zero.

The hierarchy prior had a small effect on mean correctness but a larger effect on exact completion. The no-hierarchy run reduced strict full credit from **80.0%** to **72.7%**. Figure-primary questions accounted for the largest modality-specific loss, with a **16.7-point** reduction in full credit.

We used GPT-5.6 to apply the locked correctness, completeness, faithfulness, and citation rubric. The updated answers for A2 through A6 matched the previously audited answers byte for byte, so we retained their item-level adjudications. The no-router run retained 132 prior answers and supplied 18 repaired answers; GPT-5.6 scored those repaired records against the locked gold elements. Scripts calculated every retrieval, visual-retrieval, latency, calibration, and composite metric. These results remain provisional until a second MUTCD-informed annotator reviews the changed answers and repeated runs quantify generation variability.
